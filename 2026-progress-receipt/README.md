# 2026进度小票

一个无登录的年度照片产品。用户选择5张照片后，可以生成1080×1920高清小票图片，并生成有原创氛围配乐的 10 秒 MP4 竖屏视频。

## 本地运行

产品需要 Node.js 20+ 和 FFmpeg。开发环境运行 `npm install` 后执行 `npm start`，访问 `http://localhost:3000`。

生产环境使用仓库中的 Dockerfile 部署。服务端只接收浏览器已生成的 10 秒视频片段，转码为 MP4 后即删除输入文件和成片临时文件。

## 隐私

- 照片只通过浏览器 File API 读取，不会单独上传或持久化。
- 为生成通用 MP4，浏览器会把由照片合成的 10 秒视频上传到服务端即时转码并添加原创氛围配乐。
- 输入视频和输出视频会在请求结束后立刻删除；页面刷新后照片也会被清除。

## 文件

- `index.html`：产品页面
- `styles.css`：移动端优先的视觉样式
- `app.js`：照片读取、年度进度、动画、图片/视频导出与分享
- `CAPCUT_TEMPLATE_SPEC.md`：剪映/CapCut模板时间线和替换位规格
- `LAUNCH_COPY.md`：标题、简介、关键词、封面A/B版本和发布顺序
